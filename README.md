# Personal Portfolio & SOC Analyst Landing Page

A custom multi-page personal portfolio landing page built as part of **The Odin Project** curriculum. Dedicated to showcasing a professional Security Operations Center (SOC) Analyst profile, core technical skills, and defensive security lab projects.

## Built With
* **HTML5** (Semantic structure and multi-file linking)
* **CSS3** (Flexbox, custom styling, and layout rules)
* **Font:** Google Fonts (Roboto)
* **Version Control:** Git & GitHub

## Pages Included
1. **Home (`index4.html`):** Main landing page featuring a hero section, introduction, and quick navigation.
2. **About Me (`about.html`):** Dedicated page detailing professional SOC background, log analysis experience, and core competencies.
3. **Projects (`projects.html`):** Showcase of security labs, network authentication tracking, and incident triage portals.
4. **Contact (`contact.html`):** Clean call-to-action and connection page.
